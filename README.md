# Python ATM Machine

A beginner-friendly ATM simulator built using Python.

## Features
- PIN verification with three attempts
- Check account balance
- Deposit money
- Withdraw money
- Mini statement
- Exit menu

## Technologies Used
- Python
- Loops and conditional statements
- Lists and string formatting

## How to Run
1. Install Python.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python atm.py
```

## Note
This is an educational project. It does not connect to a real bank or process real transactions.
